# Agent handoff

Đọc theo thứ tự trước khi sửa dự án:

1. `docs/PROJECT_PLAN.md`
2. `docs/ARCHITECTURE.md`
3. `agents/STATUS.md`
4. `agents/WORKFLOW.md`

Mọi thay đổi kiến trúc hoặc hành vi người dùng phải cập nhật đồng thời tài liệu liên quan. Không xóa thay đổi ngoài phạm vi. Dùng `apply_patch` cho chỉnh sửa thủ công và chạy test/build trước khi bàn giao.
